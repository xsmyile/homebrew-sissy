# Sissy Homebrew Tap

Homebrew tap for [Sissy](https://sissy.smyile.com), the menu bar companion for
developers: Claude Code and Codex limits and spend, the agents running now, the
Mac's memory, disk and network, and git.

## Install

```bash
brew install --cask xsmyile/sissy/sissy
```

The cask installs `Sissy.app` into `/Applications`.

## Update

Sissy updates itself: it checks once a day and asks before installing. The cask
is marked `auto_updates`, so `brew upgrade` leaves it to the app unless asked:

```bash
brew upgrade --cask --greedy sissy
```

## Uninstall

```bash
brew uninstall --cask sissy
```

`brew uninstall --cask --zap sissy` also removes Sissy's state in
`~/Library/Application Support/Sissy`, its preferences and its caches.

## Requirements

macOS 26 (Tahoe) or later, Apple Silicon or Intel.

## How updates land

The cask file is regenerated by
[Sissy's release workflow](https://github.com/xsmyile/sissy/blob/master/.github/workflows/release.yml)
whenever a `v*` tag is pushed. No manual editing.
